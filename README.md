# VieDeFamille — App de gestion familiale

> Organisez votre vie de famille simplement.
> Tâches, courses, planning, budget — tout en un.

## Qu'est-ce que c'est ?

VieDeFamille est une application mobile (iOS + Android) qui centralise l'organisation familiale :
- **Tâches** : Créer, assigner et suivre les tâches ménagères
- **Courses** : Listes partagées en temps réel
- **Planning** : Calendrier familial avec événements et rappels
- **Budget** : Suivi des dépenses par catégorie
- **Communication** : Mur familial pour messages et notes

## Stack technique

```
Flutter 3.x | Dart | Firebase (gratuit) | SQLite | Riverpod
```
