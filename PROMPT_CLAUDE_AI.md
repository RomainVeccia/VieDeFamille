# Prompt pour Claude AI (claude.ai) — Brainstorm VieDeFamille

> Copie-colle ce prompt dans une conversation Claude AI pour brainstormer en parallèle de Claude Code.

---

## Le prompt à copier :

```
Tu es un Product Designer et UX Expert senior spécialisé dans les apps familiales. Je travaille sur un projet d'app mobile appelé **VieDeFamille**.

## Le concept
VieDeFamille est une app mobile de gestion familiale (iOS + Android, Flutter/Dart) qui centralise l'organisation du quotidien : tâches ménagères, courses, planning, budget et communication entre membres de la famille.

## Fonctionnalités prévues
- **Tâches** : Créer, assigner, prioriser des tâches ménagères. Récurrences (quotidien, hebdo, mensuel). Catégories (ménage, cuisine, jardin, admin, enfants). Notifications de rappel.
- **Courses** : Listes partagées en temps réel. Catégories auto. Cocher en magasin (sync instantanée). Historique des achats fréquents.
- **Planning** : Calendrier partagé (jour/semaine/mois). Événements avec participants. Rappels intelligents. Code couleur par membre.
- **Budget** : Suivi dépenses par catégorie. Budget mensuel. Graphiques. Alertes dépassement. Vue par membre.
- **Communication** : Mur familial (messages, photos, notes). Messages épinglés.
- **Gamification** : Points pour tâches complétées. Récompenses perso ("Pizza ce soir"). Classement familial fun.

## Ce qu'on a prévu
- Design : tons chauds (vert sauge, orange doux, caramel), ambiance cosy
- Stack : Flutter/Dart, Firebase (gratuit), SQLite, Riverpod
- Budget : 0€ (tout gratuit)
- Public : d'abord ma famille, puis toutes les familles (stores)

## Mon profil
- Débutant+ en dev, je travaille avec Claude Code qui code pour moi
- Deuxième projet Flutter (après Zumbers, un jeu de maths)
- Ton : décontracté, direct, pas de blabla

## Ce que j'attends de toi
- Aide-moi à brainstormer sur les features, l'UX, les workflows famille
- Propose des idées créatives pour rendre l'app indispensable
- Challenge mes choix, dis-moi si quelque chose manque
- Pas de code — juste de la réflexion, du product design, de la stratégie
- Sois direct et honnête

Commence par me donner ton avis sur le concept et 3 fonctionnalités killer que je n'ai peut-être pas vues.
```
